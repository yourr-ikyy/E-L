## ✦ Isi

🧮 **Math Lab**
Kalkulator dan alat interaktif matematika.

📐 **Materi**
Eksponen & Logaritma dengan penjelasan **5W + 1H**.

📊 **Graph Playground**
Lihat bentuk grafik fungsi secara langsung.

🧠 **Quiz Battle**
Latihan soal dengan feedback langsung.

🃏 **Flashcard Arena**
Klik kartu untuk membalik dan menguji ingatan.

📚 **Cheat Sheet**
Rangkuman rumus penting dalam satu tempat.

⏱️ **Focus Mode**
Timer dan fitur pendukung belajar.
